# RenameFromParentFolder

Windows のエクスプローラーで、選択したファイルを親フォルダ名に変更します。拡張子は引き継ぎます。

## インストール・更新

- Windows x64
- Python 3.10 以降（Tkinter 付きで、`python.exe` に PATH が通っていること）
- Visual Studio または Visual Studio Build Tools の「C++ によるデスクトップ開発」（初回ビルド時とハンドラーのソース更新時）

このリポジトリのフォルダで PowerShell を開き、次を実行します。

```powershell
.\Install-ExplorerMenu.ps1
```

現在の Windows ユーザーに右クリック項目と設定用のスタートメニューショートカットを登録します。更新時も同じスクリプトを実行してください。旧版の `add_context_menu.reg` は旧バッチを呼び出すための登録ファイルです。現在の登録には上の PowerShell スクリプトを使います。

## 使い方

1. エクスプローラーで、同じフォルダ内のファイルを選択します。
2. 右クリックメニューの **親フォルダの名前に変更** を選びます。Windows 11 では **その他のオプションを表示** または `Shift+F10` で開けます。

親フォルダが `旅行` の場合、1件だけなら `旅行.jpg` のように改名します。複数件を選ぶと、初期設定では元のファイル名順に `旅行_01.jpg`、`旅行_02.png` のように連番が付きます。変更先の名前が重複しているか、別のファイルやフォルダがその名前を使っている場合は、改名を始める前にエラーを表示します。

## 複数選択時のファイル名書式

スタートメニューで **親フォルダの名前に変更の設定** と検索して開きます。書式を直接入力するか候補から選び、プレビューを確認して保存します。

| 書式の要素 | 展開される値 |
| --- | --- |
| `%parent%` | 親フォルダ名 |
| `%title%` | 元のファイル名の拡張子を除いた部分 |
| `%track%` | 元のファイル名順に 1 から振る連番 |
| `$num(%track%,2)` | `01`、`02` のようにゼロ埋めした連番。桁数は 1〜9 を指定できます |
| `%%` | パーセント記号 |

たとえば、親フォルダが `旅行` で最初のファイルが `海.jpg` の場合は次のようになります。

| 入力する書式 | 結果 |
| --- | --- |
| `%parent%_$num(%track%,2)`（初期設定） | `旅行_01.jpg` |
| `%parent% ($num(%track%,3))` | `旅行 (001).jpg` |
| `$num(%track%,2) %title%` | `01 海.jpg` |

設定は `%LOCALAPPDATA%\RenameFromParentFolder\settings.json` に保存します。

## コマンドラインで変更予定を確認する

`--dry-run` を付けると、保存済みの書式で変更予定を表示します。

```powershell
python .\RenameFromParentFolder.py --dry-run "C:\Photos\旅行\海.jpg" "C:\Photos\旅行\山.png"
```
